# Study Buddy 🤖

Study Buddy is a simple chatbot built using React that helps students learn basic programming and technical concepts.

## Features

- 💬 Chat with the bot
- ☕ Java learning support
- 💻 DSA learning support
- ⚛️ React learning support
- 🚀 Git and GitHub information
- 🤖 Basic AI/ML explanations


## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite

## How to Run

```bash
npm install
npm run dev
